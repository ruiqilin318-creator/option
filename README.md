# OPTION Project

ETF/指数期权自动分析项目。项目会在交易日自动抓取ETF行情、期权链和波动率数据，并沿用既有分析逻辑生成PDF报告。

## 功能

- 自动抓取常用品种：510300、510050、510500、159915、588000。
- 固定交易日时间运行：09:45、10:45、11:45、13:30、14:40。
- 保留原策略约束：只分析买方；方向单默认带保险腿；风险优先；输出涨跌情景、Greeks、波动率和风控建议。
- 输出PDF报告到 `reports/`。

## 安装

```bash
python -m pip install -e .
```

## 立即生成报告

```bash
option-report run-once --symbol 510300
```

省略 `--symbol` 会为配置内全部标的生成报告。

## 启动定时任务

```bash
option-report schedule
```

调度器会先通过交易日历判断是否为A股交易日；非交易日自动跳过。

## 当前分析框架

1. 抓取ETF现价和日涨跌幅。
2. 抓取期权链并规范化合约名、行权价、最新价、Greeks、IV、成交量和持仓量。
3. 抓取综合波动率面板，用于判断买方环境。
4. 按原有模板筛选偏空买方保险组合：认沽主腿 + 认购保险腿。
5. 按标的涨跌1%至9%输出情景测算。
6. 生成PDF，提示Theta、Vega、IV回落和保险距离风险。

## 配置

默认配置在 `option_report/config.py`：

- `schedule_times`：交易日自动运行时间。
- `symbols`：标的列表和保险距离。
- `holding_days`：默认3天、5天持仓观察。
- `scenario_steps`：涨跌1%至9%情景区间。
